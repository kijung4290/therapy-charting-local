# 원탑통증재활센터 치료차팅 (Windows 설치형 로컬앱)

기존 구글 앱스스크립트 기반 웹앱을 **Windows 설치형 데스크톱 프로그램**으로 전환한 버전입니다.

- **메세지미 해외 IP 차단 문제 해결:** 구글 서버를 거치지 않고 현재 PC의 국내 인터넷 회선에서 메세지미 API로 직접 발송합니다.
- **기존 스프레드시트 그대로 이전:** 구글 스프레드시트를 `.xlsx`로 내려받아 업로드하면 8개 시트(`고객명단`, `치료사`, `서비스목록`, `일정`, `차팅`, `문자발송내역`, `설정`, `오프`)가 자동으로 이전됩니다.
- **GitHub Releases 실시간 자동 업데이트:** 새 버전이 배포되면 설치된 PC에서 자동으로 감지·다운로드하고, 클릭 한 번으로 기존 데이터를 자동 백업한 뒤 최신 버전으로 업데이트합니다.
- **개인정보 완전 분리:** 고객 명단·일정·차팅·연락처·문자 내역·API Key는 **절대 GitHub에 올라가지 않으며**, 오직 사용하는 PC의 `%APPDATA%\원탑통증재활센터\therapy-charting.sqlite`에만 저장됩니다.
- **자동문자 백그라운드 실행 & 원내 공유(선택):** 창을 닫아도 시스템 트레이에서 1분마다 자동문자를 확인하며, 원내 Wi-Fi 공유를 켜면 다른 PC·태블릿에서도 동시 접속할 수 있습니다.

---

## 1. 설치 및 실행

### 설치 파일로 설치하기 (권장)
1. GitHub [Releases](https://github.com/kijung4290/therapy-charting-local/releases/latest)에서 `OneTop-TherapyCharting-Setup-x.x.x.exe`를 내려받아 실행합니다.
2. 설치를 완료하면 **바탕화면**과 **시작 메뉴**에 `원탑통증재활센터` 바로가기가 생성됩니다.
3. 최초 기본 비밀번호는 메인 접속 `1234` / 관리자 `1234`입니다. (기존 스프레드시트의 `설정` 시트를 함께 이전하면 기존 비밀번호로 자동 전환됩니다.)

### 개발/직접 실행 명령어
```powershell
npm install
npm start          # 데스크톱 앱 실행
npm test           # 자동 테스트 실행
npm run build:win  # Windows 설치파일(.exe) 로컬 빌드
```

## 2. 기존 구글 스프레드시트 데이터 이전 방법

1. 기존 구글 스프레드시트에서 **`파일` → `다운로드` → `Microsoft Excel (.xlsx)`**로 저장합니다.
2. 설치된 **원탑통증재활센터** 로컬앱 상단의 **`스프레드시트 가져오기`** (또는 관리자 인증 후 **`데이터 이전/백업`**)를 클릭합니다.
3. 내려받은 `.xlsx` 파일을 선택하면 8개 시트 건수 미리보기가 표시됩니다.
4. 최초 이전 시 **`전체 교체 (최초 이전 권장)`**를 선택하고 **`스프레드시트 데이터 이전 실행`**을 누릅니다.
   - 실행 직전 기존 로컬 DB가 `backups` 폴더에 자동 백업됩니다.
   - 구버전 시트명(`대상자명단`)과 구버전 컬럼(`대상자`, `치료내용`, `데스크 기재`, `대표님 기재`, `방문`, `상담확인`, `수납`, 고객명단 J·K열)도 자동으로 호환됩니다.

---

## 3. 메세지미 문자 설정 & 공인 IP 사전등록 (403 해결)

1. 관리자 인증 후 상단 **`문자 설정`**을 클릭합니다.
2. 상단 녹색 박스의 **`현재 PC 공인 IP`** 옆 **`IP 복사`** 버튼을 누릅니다.
3. 복사한 IP를 메세지미 관리자 페이지 또는 고객센터의 **API 발송지 허용 IP**에 등록합니다.
4. 메세지미 **API Key**, **등록된 발신번호**, **기관명**을 입력하고 저장합니다.
   - 먼저 **`모의 발송`** 및 **`잔여 캐시`** 조회로 연결을 확인한 뒤 **`실제 발송 모드`**로 전환하세요.

## 4. 실시간 자동 업데이트 동작 및 새 버전 배포 방법

### 사용자 PC (자동 업데이트)
- 앱 실행 15초 후와 이후 **30분마다** GitHub Releases를 자동 확인합니다.
- 새 버전이 있으면 백그라운드에서 자동 다운로드한 뒤 화면 상단에 **`지금 재시작하여 업데이트`** 배너를 표시합니다.
- `데이터 이전/백업` 모달 또는 시스템 트레이 우클릭 메뉴에서 **`업데이트 확인`**을 직접 누를 수도 있습니다.
- 업데이트 직전 `%APPDATA%\원탑통증재활센터\backups\`에 DB 자동 백업이 생성되며 기존 데이터는 그대로 유지됩니다.

### 개발자 (새 버전 배포 — 1줄 명령)
코드를 수정하고 커밋한 뒤 버전을 올려 태그를 푸시하면 **GitHub Actions가 자동으로 테스트 → Windows `.exe` 빌드 → `latest.yml`과 함께 Release 게시**까지 완료합니다.
```powershell
npm version patch           # 예: 1.0.0 -> 1.0.1 자동 커밋 + 태그 생성
git push --follow-tags      # GitHub Actions가 자동으로 새 설치파일 배포
```

## 5. 개인정보 보호 및 데이터 저장 위치

- **GitHub에 올라가는 것:** 프로그램 소스 코드 및 설치 파일(`OneTop-TherapyCharting-Setup-*.exe`)만 포함됩니다.
- **GitHub에 절대 올라가지 않는 것 (`.gitignore` 차단):** `.sqlite`, `.db`, `.xlsx`, `.xls`, `.csv`, `.ods`, `.env`, `backups/`, `.local-data/`
- **로컬 데이터 저장 위치:** `%APPDATA%\원탑통증재활센터\therapy-charting.sqlite`
- **백업 폴더:** `%APPDATA%\원탑통증재활센터\backups\`
